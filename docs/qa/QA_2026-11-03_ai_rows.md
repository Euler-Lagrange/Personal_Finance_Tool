# Reviewed AI transaction rows - November 3, 2026

## Scope

Schema 32 connects completed AI transaction proposals from PDF/image evidence to the normal import queue. The row editor supports corrections, adding missing rows, removal, dates, exact decimal amounts, direction, posting status, currency and source page/quote. Preview and a separate acknowledgement precede staging. The original provider output remains unchanged; reviewed corrections reopen from saved history.

Staging replaces only unprocessed source rows and creates no spending. Account/column review and individual transaction confirmation still follow. Native assisted markers and bindings block bulk/automatic processing and complete-coverage claims. Unknowns remain held, and the existing posted-USD, account/direction, duplicate, refund and payment rules remain authoritative. Structured CSV/Excel files retain their column-mapping workflow. Bill/statement adoption and declarative mapping/template suggestions remain next.

## Findings and integration

- Review tokens include source revision, prior dataset, original proposal and corrected rows. Edited or stale previews fail. An injected audit failure rolls back the review, binding, dataset and rows together. A repeated operation does not create a second staging result.
- Saved corrections are loaded before an existing row review becomes editable. Failed reads have a retry control; delayed previews cannot replace later edits. Closing a dirty draft requires deliberate discard. Unsent request drafts and unsaved column edits are protected from staging navigation.
- Restored assisted flags, raw cells, parsed candidates and original-proposal hashes were individually corrupted in isolated backups. Each restore was rejected while the current workspace remained unchanged. Stale/dismissed sources are held; bindings survive observations and valid restore. Local PDF table extraction and AI staging cannot overwrite each other's retained rows.
- The synthetic accounting integration posts five purchases totaling **$624**, preserves two identical Store purchases, then records a **$624 card payment**. Spending stays $624 and the card's recorded net activity is zero. A later CSV links all six existing events once; a later $10 refund reduces only its received month. Observations and backup/restore retain all amounts and evidence.
- A synthetic image-source test holds unknown posting status/currency, permits explicit reviewed correction, and then imports once. The image's original bytes and assisted review policy remain available after restore. This exercises the staged workflow, not vision accuracy.
