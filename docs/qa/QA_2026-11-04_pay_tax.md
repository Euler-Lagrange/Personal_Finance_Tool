# Offline withholding and calibration — November 4, 2026

## Scope

Section 4 implements reviewed year/election/deduction profiles, explicit historical and forecast YTD context, native 2026 federal/Kentucky/FICA estimates, configured local withholding, and bounded calibration from compatible earlier known paychecks. Predictions retain their inputs, tax lines and supporting comparisons. This section creates no ledger income or expected cash deposit. All development records, archives and tax elections were synthetic; real paystubs were not opened.

Official methods and the Kentucky example discrepancy are documented in [the design](../design/PAY_WITHHOLDING_DESIGN.md). This is an ordinary modern-W-4 W-2 withholding model, not a tax-return estimator. Missing context and unsupported years produce an unavailable estimate; manual and known-pay methods remain available.

## Findings and corrections

- A capped benefit initially required prior YTD usage even on a benefits deduction holiday. The focused test reproduced an unavailable estimate for a valid holiday paycheck; applicability now controls both the cap-context requirement and deduction. Fixed dates on another payday likewise do not apply.
- Exact-label browser interaction exposed the profile selector's ambiguous implicit accessible name. An explicit label association fixes selection. Initial test navigation also used an incorrect tab name; the test was corrected to the actual Pay settings/Weekly hours labels.
- Editing profile choices clears its reviewed flag. Editing per-payment YTD clears its confirmation; every prediction input edit clears the preview. Unchanged retries reuse the operation ID after a simulated lost response, preserving one record and the user's draft.
- Historical comparisons keep the original fact/profile/YTD calculation after a later correction, and become ineligible for calibration. Saved predictions retain original amounts. Empty new fields remain omitted for old snapshot hashes; legacy forecasts still replay with model version 1, while tax forecasts use version 2.
