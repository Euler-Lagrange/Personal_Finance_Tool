# PDF transaction-table extraction

This checkpoint turns supported text-PDF tables into the existing import dataset and review pipeline. It does not introduce a second ledger. Templates use an exact document identity and USD line on page one, an exact table-start and table-end line on every page, named columns, and one of four bounded layouts: pipes, tabs, runs of spaces, or one cell per text line. Every nonempty line between the markers must belong to a complete row; ambiguous markers, malformed widths and unsupported continuation layouts block staging. Original page/line evidence is retained for every row. Arbitrary scripts and regular expressions are not accepted.

Preview the sample before approving an immutable template version. An optional approval choice allows later matching documents to stage locally. Automatic recognition requires exactly one enabled template identity match and a successful extraction; competing templates or changed layouts remain held. Staging creates only pending import rows, resets source interpretation/coverage and creates no financial event. Existing account/column/coverage/profile confirmation, matching, refunds, transfers, rules and undo govern subsequent posting. Explicitly confirmed complete coverage is available only for PDFs with validated table provenance.

Versions retain sample evidence. Source bindings retain the exact version, extracted rows and page/line locations. Re-extraction of a bound/approved source is protected; a new observation is available. Processed rows cannot be remapped. New observations copy provenance while renewing source interpretation and coverage. Operation receipts, atomic writes, stale previews, restore re-evaluation and workspace isolation are tested with synthetic PDFs/SQLite and mocked browser commands.

General spatial tables, wrapped descriptions and arbitrary issuer layouts remain unsupported until a reviewed adapter handles them. Source evidence is text plus original export; no original-PDF canvas is claimed. Document fields and table rows remain separate applications of the same evidence.
